# Support

OpenVisionSearch is maintained by volunteers. Please use the right channel so
questions and defects remain searchable for future users.

## Ask for help

Before opening an issue:

1. Read the [quickstart](README.md#quickstart),
   [deployment guide](docs/deployment.md), and
   [API reference](docs/api-reference.md).
2. Search existing issues for the error message or behavior.
3. Reproduce with the newest release or the `main` branch when practical.

Use the question issue form for configuration and usage help. Include versions,
the relevant configuration with secrets removed, a minimal request, and sanitized
logs. Response times are best effort; no service-level agreement is provided.

Use the bug form for reproducible defects and the feature form for proposals.
Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md) and must not be
reported publicly.
